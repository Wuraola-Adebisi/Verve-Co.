# Verve & Co.

Verve & Co. is an early MVP for a fashion storefront, designed to give shoppers a clear, brand-led way to browse a collection and move through a shopping flow.

The current experience focuses on the essentials: exploring product categories, viewing product listings, adding items to a slide-out cart, and moving through the checkout interface. The visual direction is editorial and minimal, with a considered palette, custom typography, and responsive layouts across screen sizes.

## What works in this MVP

- Multi-page storefront with home, tops, dresses, pants, about, contact, and checkout pages
- Product category browsing and responsive product grids
- Slide-out cart with client-side cart state saved in the browser
- Checkout interface to demonstrate the intended purchase journey
- Responsive navigation and mobile-friendly layouts
- Contact form interface and brand information pages
- Consistent visual identity, product imagery, and editorial product copy

## Current scope

This is a front-end MVP. Cart data is stored in the browser using `localStorage`, so it is specific to the shopper's browser and device. The current build does not include a connected inventory system, customer accounts, order management, or live payment processing. The checkout page represents the purchase flow; it should not be treated as a completed live-commerce transaction system.

These are deliberate boundaries of the current version, not claims of functionality that has already been implemented.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Cloudinary-hosted product imagery

## Project direction

The MVP establishes the storefront experience and the main shopping interactions. Future development can build on this foundation with a product and inventory source, persistent customer carts, order handling, and a payment provider when the business is ready for live transactions.
